# Images de la page d'accueil

Déposez ici deux fichiers (facultatifs). En leur absence, la page reste correcte :
le fond devient un aplat institutionnel et le drapeau du Sénégal remplace l'emblème.

| Fichier | Rôle | Si absent |
|---|---|---|
| `armoiries-senegal.png` | Armoiries officielles de la République (haut du volet gauche) | drapeau du Sénégal (SVG) |
| `portail-hero.jpg` | Photo de fond du volet gauche (agents, bâtiment du Ministère…) | fond dégradé vert/or/rouge |

## Recommandations

- **Armoiries** : PNG à fond transparent, ~300 px de haut. Version officielle
  (lion, baobab, étoile verte) fournie par la communication du Ministère.
- **Photo** : orientation portrait, sujet vers le haut (le bas est assombri),
  ~1400 × 1800 px, JPG qualité 80, < 400 Ko. Sujet en lien réel avec le portail :
  agents du Ministère à leur poste, guichet, façade institutionnelle.
- Photo libre de droits acceptée (Unsplash / Pexels — licence gratuite) si aucune
  image officielle n'est disponible.

Aucune modification de code n'est nécessaire : il suffit de déposer les fichiers
avec ces noms exacts, puis de recharger la page.
